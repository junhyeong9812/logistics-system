# WMS System

> 스택 가정: Spring Boot(Kotlin) + JPA, PostgreSQL. 상세 정리는 OMS, PMS 다음 순서에 한다. 지금은 OMS 논의에서 먼저 정해진 것만 적는다.

## 쟁점 (선결정)

| # | 쟁점 | 결정 |
|---|---|---|
| W1 | 창고 간 재고 보충 | 창고 x SKU별 가용 재고가 기준량의 10% 이하가 되면 보충 요청을 만든다. 기준량 = 창고 x SKU별 적정 재고 설정값 [정의 확인 필요]. 보충은 SKU 수량 단위 창고 간 이동(출고 -> 운송사 구간 -> 입고, TMS T1)이고 주문 단위가 아니다. OMS 해외 주문의 `export_stock_ready` = F도 같은 이동 요청 경로를 쓴다(OMS 9번). 이동분이 도착 창고에 **입고 완료되면 가용 재고에 더해지고, 수출 재고를 기다리던 주문(F)부터 먼저 할당**한 뒤 남는 수량을 일반 가용으로 푼다. 미정: 보충 수량 계산식, 이동 중 수량을 반영해 중복 요청을 막는 방식, 출발 창고에도 재고가 없을 때(셀러 입고 요청 알림) |
